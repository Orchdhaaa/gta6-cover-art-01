Vice Cover Studio turns your photos into a GTA-style cover. Pick from 3 multi-panel layouts, place a photo in each panel, pan and zoom to get the framing right, add a caption and a colour grade, then export a crisp PNG at 1080x1080, 1080x1350, or 1920x1080. Everything runs locally, so your photos never leave your device.

## Run it

```sh
node serve.ts
```
